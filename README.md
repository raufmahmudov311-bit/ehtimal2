# Ehtimal Akademiyası

## Kompüterdə yoxlamaq (istəyə bağlı)
1. Node.js 20+ quraşdırın.
2. Qovluqda: `npm install`, sonra `npm run dev`.

## Vercel-ə yükləmək
1. ZIP-i açın, qovluğu GitHub-da yeni repozitoriyaya yükləyin.
2. vercel.com → Add New → Project → repozitoriyanı seçin → Deploy (ayarları dəyişməyin).
3. Build xəta versə, xəta mətnini mənə göndərin.

İrəliləyiş brauzerin yaddaşında (localStorage) saxlanır.
